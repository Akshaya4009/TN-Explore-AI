# TN Explore AI — Full Working Demo

This portfolio demo contains **348 Tamil Nadu discovery records**.

## Features
- Tamil Nadu-wide district/region selector
- 330+ demo locations
- Tourist + heritage + nature + spiritual + culture
- Shopping/malls + cinemas/entertainment + food/local discovery
- Search and category filters
- AI-style personalized trip planner
- Budget estimate
- Eco score
- Responsible tourism section
- Landmark image-analysis demo endpoint
- Flask backend + SQLite-ready JSON dataset
- Responsive frontend

## Run in VS Code / Windows

```powershell
py -m venv venv
venv\Scripts\activate
python -m pip install -r requirements.txt
python app.py
```

Then open **http://127.0.0.1:5000**

The dataset is for academic/portfolio demonstration. Verify current timings, prices, movie schedules and availability before real travel.
